## 1. 核心诉求与演进动机

在 v0.1.0 的实际测试中，我们发现仅沿屏幕四周 16:9 矩形画框对于全屏场景切换来说，视觉上容易退化为“外边框发光 + 中心圆形渐显”，缺乏 Manim 真正震撼人心的**“内部公式、文字、窗口、人物被一笔一划当场画出”**的几何之美。

**v0.2.0 的核心突破点**：
将任意复杂的输入画面实时抽象为**几何线条稿（Chalkboard Wireframe / Contour Vectorization）**，让进退场动画作用于画面内部的具体轮廓线上，实现真正意义上的 `DrawBorderThenFill` 与 `Uncreate`。

---

## 2. 核心算法选型与可行性调研

### 2.1 方案一：GPU 实时轮廓素描场（XDoG / Sobel-Scharr 边缘提取）—— ⭐⭐⭐⭐⭐ (默认首推)
* **算法原理**：
  在 GPU 像素着色器中，利用 **扩展高斯差分（eXtended Difference of Gaussians, XDoG）** 或 **Scharr 梯度算子**：
  $$\nabla I(x, y) = \sqrt{G_x^2 + G_y^2}$$
  配合局部双边滤波或自适应阈值，在小于 0.4ms 内将 1080p 视频帧转换为纯黑底色的高对比度**“几何粉笔线稿（Edge Contour Map）”**。
* **动效时序流程**：
  * **退场（Uncreate）**：旧场景色彩在 0.2 秒内迅速退去，原位转变为荧光线稿骨架；随后线条反向收缩断裂消散。
  * **进场（Create）**：新画面并不直接展示，而是暗场中先由高光激光/粉笔线勾勒出所有文字、按钮、UI 和主体轮廓；随后画面真实色彩由线条内部如墨水般注入浸润（Infill），融为最终画面。
* **工程优势**：无任何外部重量级依赖（无需 OpenCV 或深度学习），单 Shader Pass 纯 GPU 并行完成，天然支持 60fps+ 实时推流。

### 2.2 方案二：频域傅里叶谐波模式（GPU 2D FFT / Fourier Epicycles）—— ⭐⭐⭐⭐☆
* **算法原理**：
  致敬 3Blue1Brown 最著名的“傅里叶级数旋转圆环作图（Fourier Epicycles）”。
  在实时着色器中，通过频域高通谐波滤波提取出图像的频域主能量轨迹，或者在画面边缘采样生成若干组旋转正弦波谐波圆环。
* **视觉呈现**：
  转场触发时，画面轮廓伴随正弦波动与高频谐波脉冲展开，呈现出极具数学公式与信号处理质感的谐波波动扫描效果。

## 3. UI 交互设计与功能规格 (v0.2.0)

在 OBS 转场属性面板中，新增以下核心控制项：

```
[ 几何轮廓提取模式 (Contour Extraction Mode) ] (下拉单选)
  ├── 1. GPU 轮廓素描 (XDoG 实时线稿) —— [默认推荐]
  ├── 2. 频域傅里叶谐波 (Fourier Harmonic Wave)
  └── 3. 关闭 (传统 0.1.0 纯外框模式)

[ 轮廓提取灵敏度 (Contour Sensitivity) ]
  [ 0.05 ──────────●────────── 0.50 ] (默认 0.22)

[ 线稿高光风格 (Line Stroke Style) ]
  [ 经典黑板白 | 黄金流光 | 霓虹赛博青 | 自定义边框颜色 ]

[ 色彩浸润填充延迟 (Fill-In Delay %) ]
  [ 10% ────────────●──────── 80% ] (默认 45%)
```

## 4. 自动化 Releases 发布流程规划

为了彻底摆脱手动从 Actions 下载 Artifacts 的繁琐流程，v0.2.0 将引入**标准语义化 Tag 触发的 GitHub Releases 自动化构建管线**：

1. **触发机制**：推送 `git tag v0.2.0`。
2. **构建与打包**：
   * Windows x64：自动打包输出标准解压包 `obs-manim-motion-v0.2.0-windows-x64.zip`。
   * Linux x64：自动生成 Debian/Ubuntu 安装包 `obs-manim-motion-v0.2.0-ubuntu-x86_64.deb` 及通用 tarball。
3. **自动发布**：流水线通过 `softprops/action-gh-release` 自动创建 GitHub Release，将上述产物及 SHA256 校验码自动挂载至 Release 页面，供用户一键直链下载。
