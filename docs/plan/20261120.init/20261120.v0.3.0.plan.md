## 1. 深度溯源：Manim 源码中 `Write` 与 `Create` 的本质差异

在 Manim 官方源码（`manim/animation/creation.py`）中：

```python
class Write(DrawBorderThenFill):
    def __init__(self, vmobject, rate_func=linear, reverse=False, **kwargs):
        run_time, lag_ratio = self._set_default_config_from_length(vmobject, ...)
        super().__init__(vmobject, rate_func=rate_func, lag_ratio=lag_ratio, ...)
```

* **`Create`（$Create \equiv DrawBorderThenFill$）**：
  * 本质是**空间结构的同时展开**——所有线条沿自身路径同时行进，或者以几何中心为圆心径向扩散。
  * 视觉感受：**“物体降临/几何构造构建”**。
* **`Write`（$Write \subset DrawBorderThenFill + \text{Lag Ratio} + \text{Topology}$）**：
  * 本质是**人类书写与黑板推导演算的时空连续性**：
    1. **时差滞后（Lag Ratio）**：子笔画/文字不是同时出现，而是前一个笔画写完 $k\%$ 时，下一个笔画才接入；
    2. **局部拓扑行序（Reading Order）**：严格遵循人类阅读与板书习惯（由上至下、由左至右的一行行推进）；
    3. **笔尖跟随（Pen Tip Lead）**：在行进的最前沿永远存在一个高动能的焦点（落笔点）。
  * 视觉感受：**“有智慧主体正在黑板上一笔一划推导公式、书写文字”**。

## 2. OBS 实时视频渲染流中实现 `Write` 的算法选型与技术可行性

在 OBS 中，输入的场景画面（PPT 幻灯片、代码窗口、网页、摄像头）已经是光栅化的 GPU 纹理（Texture）。要在 60fps+（单帧低于 0.5ms）且无外部矢量依赖的前提下实现极致逼真的 `Write`，有以下三种方案：

### 2.1 方案 A：基于时空行序场与前沿笔尖光斑的 GPU 实时光笔书写 —— ⭐⭐⭐⭐⭐ (首选核心架构)

* **算法机制**：
  1. **构建时空推进场（Spatio-Temporal Flow Field, $T_{\text{flow}}$）**：
     为画面建立行序映射函数：
     $$T_{\text{flow}}(u, v) = \text{frac}(v \cdot N_{\text{rows}}) \times w_x + u + \text{PerlinNoise}(u, v) \cdot \delta$$
     将 2D 平面展开为一条自左至右、逐行向下流动的**一维时间线**。
  2. **线稿轮廓受时空场调制**：
     结合 v0.2.1 已成熟的 3×3 Scharr 梯度线稿图 $E(u, v)$，像素是否被“画出”取决于当前归一化进度 $p$ 与局部 $T_{\text{flow}}$ 的关系：
     $$\text{stroke}(u, v) = \text{smoothstep}(T_{\text{flow}} - \text{width}, T_{\text{flow}}, p)$$
  3. **笔尖落笔耀斑（Pen Tip Sparkle）**：
     在时间前沿点 $(u_t, v_t)$ 计算高斯衰减高光点：
     $$\text{TipGlow}(u, v) = I_{\text{glow}} \cdot \exp\left(-\frac{\|\text{UV} - \text{Tip}_{\text{UV}}\|^2}{2\sigma^2}\right)$$
     如同激光笔或荧光粉笔直接在黑板上飞速书写。
  4. **色彩滞后注入（Lagged Color Infill）**：
     笔尖掠过之处，荧光线条立刻被激活；滞后一定时间后，真实画面的色彩与纹理才从线稿中浸润析出，完美复刻 Manim `Write` 的 `lag_ratio`。
* **工程可行性**：纯 HLSL 像素着色器运算，不消耗 CPU 资源，无论画面包含几千个汉字、复杂的代码还是高分图像，开销恒定在 0.3ms 左右，彻底杜绝掉帧。

---

### 2.2 方案 B：频域傅里叶 Epicycles 谐波光环引导（Fourier Epicycles Pen Lead）—— ⭐⭐⭐⭐☆ (数学美学彩蛋)

* **算法机制**：
  * 汲取 3Blue1Brown 最具代表性的“旋转圆环矢量链（Fourier Epicycles）”。
  * 在当前书写前沿的“笔尖”位置，利用数学解析式渲染 3~5 个旋转嵌套的半透明正弦谐波圆环与旋转指针。
  * 视觉呈现：圆环最末端牵引着光笔，笔尖划过之处“织出”画面中的文字和公式，极具高维数学与算法推导的仪式感。

---

### 2.3 方案 C：骨架细化与笔顺图提取（Morphological Thinning）—— ⭐⭐☆☆☆ (评估暂不采纳)

* **原理**：利用 GPU Compute Shader 运行 Zhang-Suen 细化算子提取单像素骨架并构建连通图追踪笔顺。
* **淘汰原因**：迭代算法在 4K/1080p 下需要数十次 Pass，不仅极耗显卡算力，且遇到游戏画面或摄影人脸等复杂纹理时无法提取有效笔顺，泛化性极差。
